# CardioMonitorApp — Android-прототип

Приложение на Kotlin/Jetpack Compose подключается к ESP32-C3 в общей Wi-Fi-сети:
автоматически находит прибор, получает текущие показания и копирует всю завершённую
историю CSV с microSD. Прошивка самого прибора написана на C++.
APK устанавливается на телефон; приложение не копируется на SD и не входит в скетч.

[Подробная инструкция подключения, протокол v1 и ограничения](../Monitor%20soft/docs/local-link.md).
[Прошивка](../Monitor%20soft/README.md).

## Как пользоваться

Подключите прибор и телефон к одной сети, откройте приложение и запустите измерение
на приборе. IP вводить не нужно: используется Android NSD/mDNS. Интернет не нужен для обмена;
ESP32 использует его самостоятельно для синхронизации даты через NTP.
Вкладка «Устройство» показывает связь, состояние записи/SD/сигнала и ход синхронизации.
Завершённые записи проверяются каждые 15 секунд, открытая запись — после остановки.
Кнопка синхронизации ускоряет следующую проверку. При ошибке связи повтор автоматический.
Для надёжной передачи держите приложение открытым: фонового сервиса пока нет.

Главная показывает доступные достоверные ЧСС, SpO₂ и поток ЭКГ в соответствующем
режиме прибора. При обрыве связи старые значения скрываются после тайм-аута до 5 секунд.
Пустые значения не заменяются демонстрационными данными.

История хранится на телефоне и доступна без прибора. График листается окнами по
4 секунды; исходный CSV экспортируется через системный выбор файла. Удаление убирает
сессию и оригинал из приложения, не затрагивая SD. Отметка импорта сохраняется, чтобы
удалённая копия не появлялась снова при автоматической синхронизации.
Новые записи содержат дату начала, полученную самим ESP32 через NTP. Приложение
показывает её в часовом поясе телефона. Для старых CSV без даты остаётся «Дата неизвестна»
и имя файла; дата скачивания не подставляется вместо даты замера. Старые неподдерживаемые схемы CSV доступны как оригинал без интерпретации.

Оформление всегда светлое. Амплитуда ЭКГ относительная, не мВ. Оценка качества —
признак прошивки, не аппаратное определение контакта электродов. Медицинских диагнозов
приложение не ставит; правила анализа истории самой прошивки сюда не перенесены.

## Хранение и поток данных

`NSD → DeviceConnectionManager → snapshot → ViewModel → Compose` обслуживает живые
показания без записи каждого сетевого кадра в БД. Источник истории — файлы SD:
`LIST → GET → .part → CRC32 → оригинальный CSV → Room-транзакция → история`.
Индекс файлов тоже читается с диска, а не собирается целиком в RAM.

Приватные файлы: `files/sd_archive/<device>/<name>.csv`; БД:
`cardio_monitor_encrypted.db`; индекс завершённого импорта: `sd_import_v1` в
SharedPreferences. Идентичность для пропуска повторного скачивания: прибор + имя +
размер. Это рассчитано на неизменяемые CSV прошивки; ручная замена содержимого тем же
числом байт не обнаруживается. Имя сессии — прибор + файл, повторный импорт
обновлённого файла заменяет соответствующую сессию транзакционно.

CSV не теряет исходные строки и метаданные. БД содержит достоверные отсчёты ЭКГ;
для статистики пульс/SpO₂ сохраняются не чаще раза в секунду. График читает только
запрошенные 4 секунды; массив всей ЭКГ для импортированной записи не загружается.
При неизвестном формате сохраняется исходный CSV без вычисленных показателей.

## Сборка и тесты

JDK 17, Android SDK 34, Gradle 8.7, AGP 8.5.2, Kotlin 1.9.25,
Compose compiler 1.5.15, minSdk 26, targetSdk 34. Откройте эту папку в Android Studio.
Локальный SDK задаётся в неотслеживаемом `local.properties`.

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Это не прошивка ESP32.
Тесты проверяют границы JSON и двоичного тела CSV, усечённые/чрезмерно длинные строки,
обход путей, обе схемы оптических файлов, смешанный ECG/PPG, флаги пригодности и NaN.
Аппаратные проверки локального обмена описаны в [local-link.md](../Monitor%20soft/docs/local-link.md).

## Оставшиеся ограничения

- TCP в локальной сети без TLS и сопряжения. Используйте доверенную сеть. ID из mDNS
  не является удостоверением подлинности; CRC32 не является криптографической защитой.
- Исходные CSV лежат в приватном каталоге без дополнительного шифрования. Ключ
  SQLCipher всё ещё общая заглушка `REPLACE_WITH_KEYSTORE_DERIVED_KEY`; защита
  через Android Keystore и биометрическая блокировка не реализованы.
- Нет гарантии синхронизации при закрытом приложении/уснувшем телефоне. Нет выбора
  из нескольких приборов; сценарий рассчитан на один прибор и один телефон.
- Пока нет аппаратных часов с батарейкой, переноса клинического анализа прошивки, медицинской калибровки
  или самостоятельного диагностического анализа в Android.
- Нет миграций Room и каталога экспорта схем. При изменении структуры БД потребуется
  миграция. Текущая интеграция не меняет таблицы.

## Что не коммитить

`build/`, `app/build/`, `.gradle/`, `.kotlin/`, `.idea/`, `*.iml`, `*.hprof`,
`local.properties` — локальные результаты и настройки. Ключи подписи, БД и личные
измерения не публикуются и не удаляются при очистке сборки. Gradle Wrapper и исходники
обязательно сохраняются. Правила: [корневой .gitignore](../.gitignore).
